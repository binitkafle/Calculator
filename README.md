# Modern Calculator

A sleek, modern calculator built with HTML, CSS, and JavaScript featuring a beautiful dark theme and smooth animations.

## Features

- ✨ Modern, elegant dark theme design
- 🎨 Smooth animations and transitions
- 📱 Fully responsive for all devices
- ⌨️ Keyboard support
- 🧮 All basic arithmetic operations
- 💯 Percentage calculations
- ➕➖ Positive/negative number toggle
- 🔢 Decimal point support
